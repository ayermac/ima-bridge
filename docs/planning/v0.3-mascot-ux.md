# v0.3 Mascot UX & Testing Foundation

## 阶段清单

- [x] v0.3.1 Loading & Empty States
- [x] v0.3.2 App Visual Polish
- [x] v0.3.3 Mascot Asset Integration
- [x] v0.3.4 Testing Foundation

## v0.3.1 Loading & Empty States
- AppState 组件体系（LoadingState / EmptyState / SuccessState / ErrorState）
- 纯 CSS 动画，接入 LoginPanel / KnowledgeBaseList / DocumentList / DownloadQueue
- 支持 `prefers-reduced-motion`

## v0.3.2 App Visual Polish
- Design token 体系（radius / shadow / spacing / 字体栈）
- 全局布局密度、表格列宽、长文本截断、响应式换行
- 零新增依赖

## v0.3.3 Mascot Asset Integration
- 5 张 SVG mascot 素材（idle / loading / empty / success / error）
- Mascot 组件（variant / size / animated / onError fallback）
- AppState 自动根据 variant 渲染 mascot
- 包体增量约 10 KB

## v0.3.4 Testing Foundation
- Vitest 测试框架（node 环境，零 DOM 测试）
- 覆盖模块：
  - `path-utils` — 路径清理、Windows 保留名、截断、扩展名保留
  - `duplicate-utils` — 时间戳重命名
  - `queue-store` — 队列状态恢复规则
  - `env` — `.env` 解析、凭证预览、配置优先级
  - `ima-open-api` — `inferMediaType`、HTTP/业务错误处理、凭证不泄露
- 76 个测试全部通过
- 不调用真实网络、不读取真实 `.env`、不打印 token
